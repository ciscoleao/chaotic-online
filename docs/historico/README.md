# Histórico de desenvolvimento

Esta pasta preserva notas, fontes do Dromo, patches e testes das versões anteriores à organização de 7 de outubro de 2026.
Eles registram decisões e correções, mas podem apontar para HTMLs, capturas de tela e pastas antigas.
Não execute esses patches sobre `game/index.html` sem revisar sua compatibilidade.

As verificações da versão atual são executadas com `npm test`, e a publicação está documentada em `docs/PUBLICAR.md`.
As imagens de depuração e os exports antigos podem ser recuperados no histórico Git.
